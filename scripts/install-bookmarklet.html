⚙️ Step 1 — Start the Local Server

1

Open a terminal in your project folder and run:

cd C:\Users\Harshita\jaivik-seo
node scripts/data-collector.js
2

Leave that terminal open. The server runs at localhost:3456 and writes to data/universities-scraped.json.

💡 You only need to start the server once per session. You can keep it running in the background while you browse.

🔖 Step 2 — Install the Bookmarklet

1

Make sure your browser shows the Bookmarks Bar (Ctrl+Shift+B in Chrome/Edge).

2

Drag this button to your bookmarks bar:

📊 JOC Save University

🚀 Step 3 — Use It

1

Go to any university website or KC portal (e.g., findamasters.com, mastersportal.eu, university official site).

2

Click 📊 JOC Save University in your bookmarks bar.

3

A panel slides in from the right with auto-extracted data. Review and correct any fields.

4

Click 💾 Save to JSON. Data is written to data/universities-scraped.json.

Auto-extracted fields:

✓ University Name ✓ Country & City ✓ Course Name ✓ Duration ✓ Tuition Fees ✓ IELTS / PTE Min ✓ Intake Months ✓ Entry Requirements ✓ Application Deadline ✓ Source URL

📁 Step 4 — Using the Saved Data

1

All entries are saved to data/universities-scraped.json in a format compatible with your Next.js data structure.

2

View all collected data at: http://localhost:3456

3

Re-visiting the same university (same name + country) will update the existing entry, not create a duplicate.
